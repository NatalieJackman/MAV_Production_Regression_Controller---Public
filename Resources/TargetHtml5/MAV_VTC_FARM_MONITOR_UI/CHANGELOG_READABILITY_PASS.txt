MAV VTC FARM MONITOR UI - Readability Pass

Purpose
-------
Improve the Resident Field Advisor and Guided Field Validation screens for fast field scanning on a laptop without changing any Farm-side behavior or control path.

- No VTC Farm, SDK, EISC, routing, or command behavior changed.
